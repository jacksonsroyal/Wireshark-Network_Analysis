# Wireshark Network Analysis Lab

## Overview

In this lab, I captured and analyzed live network traffic using Wireshark to understand how common protocols communicate across a network.

The objective was to identify and inspect DNS queries, TCP connection establishment, and TLS encrypted communication while documenting the packet flow.

---

## Objectives

- Capture live network traffic
- Analyze DNS resolution
- Examine the TCP three-way handshake
- Inspect TLS Client Hello packets
- Practice packet filtering
- Document findings
